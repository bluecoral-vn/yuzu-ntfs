# Yuzu NTFS 0.1.1 Beta (3)

## English

- Added signed automatic update checks through https://yuzu.today/ntfs/appcast.xml using Sparkle 2.10.0. Check manually from **Check for Updates…**, or change automatic checks in **Settings…**.
- Updates wait while Yuzu NTFS or another FSKit filesystem is mounted. Eject those drives to resume installation automatically. Unknown mount inventory also blocks installation.
- After an update changes the filesystem module UUID, the app restores a previously enabled module through the existing guarded enable/refresh operation when no FSKit volume is active; otherwise it asks you to eject and enable the module.
- **0.1.0 users must install 0.1.1 manually once**: eject all FSKit drives, quit Yuzu NTFS, replace the app in Applications, then open it. Subsequent versions use the updater.
- Apple silicon, macOS 26 or later. Beta filesystem software: keep backups and eject safely.

Download: https://yuzu.today/ntfs/download

## Tiếng Việt

- Thêm kiểm tra bản cập nhật tự động có chữ ký qua yuzu.today bằng Sparkle 2.10.0. Chọn **Kiểm tra bản cập nhật…** trong menu hoặc thay đổi kiểm tra tự động trong phần cài đặt.
- Tạm hoãn cài đặt khi ổ Yuzu NTFS hoặc hệ thống tập tin FSKit khác đang được gắn. Tháo an toàn các ổ này để tự tiếp tục cài đặt. Không đọc được danh sách ổ cũng sẽ chặn cài đặt.
- Sau cập nhật, nếu UUID mô-đun thay đổi, ứng dụng tự bật/làm mới mô-đun đã được bật trước đó khi không có ổ FSKit hoạt động; nếu có, ứng dụng yêu cầu tháo ổ và bật lại.
- **Người dùng 0.1.0 phải cài thủ công 0.1.1 một lần**: tháo an toàn tất cả ổ FSKit, thoát Yuzu NTFS, thay ứng dụng trong Applications rồi mở lại. Các phiên bản tiếp theo dùng trình cập nhật.
- Apple silicon, macOS 26 trở lên. Đây là phần mềm hệ thống tập tin beta: luôn sao lưu và tháo ổ an toàn.

Tải xuống: https://yuzu.today/ntfs/download
